# Security policy

## Reporting a vulnerability

Please do not publish exploitable SSRF, XML parsing or HTML sanitization issues in a public GitHub issue. Use GitHub's **Security → Report a vulnerability** feature for this repository.

Include reproduction steps, affected endpoint and expected impact. Do not include credentials or personal feed content. Reports will be acknowledged as soon as practical.

## Deployment note

The public instance is a demonstration service. Operators handling sensitive workloads should deploy their own instance and enforce outbound network controls in addition to the application-level protections.
